# Source Register and Open Verification Items

This site is based on the project information preserved from the CargaExpress backlog discussions. The original approved backlog, acceptance criteria, ERD, and repository code remain the authoritative sources when exact details are required.

## Source topics captured

- **Backlog — Sprint 1: Discovery and Design:** RN-01–RN-10, canonical states and transitions, architecture, data model, F1–F7, and Sprint 1 backlog.
- **Backlog user-story restructuring:** consistent As a/I want/So that format, Given/When/Then acceptance criteria, traceability matrix, and team review.
- **HU-18 / RIWI-89 Type B API simulator:** tracking-number endpoint, configurable rate limiting, error scenarios, and simulator contract.
- **Sprint 3 backlog:** HU-26–HU-40, orchestration, business-day SLA/risk rules, AWS deployment, dependencies, priorities, and technical tasks.
