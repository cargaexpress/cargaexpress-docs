## Functional capability areas confirmed in the project context

- Shipment event ingestion from push, pull, and file sources.
- Canonicalization of carrier-specific shipment statuses.
- Shipment/order visibility and traceability.
- SLA and risk evaluation.
- WMS support for orders, labels, picking, fulfillment, and dispatch.
- Operational data preparation for reporting and periodic billing/settlement.
