## Delivery status principles

- **Planned** means the capability is in the backlog or architecture target.
- **In progress** means implementation has started but acceptance evidence is incomplete.
- **Implemented** requires code/configuration and test evidence.
- **Accepted** requires review against the acceptance criteria and Definition of Done.
